# 跨系统业务工具使用指南

## 核心原则

**最少调用，按需处理。**

1. **批量优先**：一次调用拉够数据（设足分页/过滤），不拆多次试探
2. **按需分析**：匹配用户意图——简单查询直接返回结果，分析需求才做本地计算
3. **不重复查**：已拿到的数据本地复用，不对同一数据源重复请求

## 取数模式

先读工具描述确认参数格式，然后：
1. 一次调用拉取原始数据（分页设足、过滤条件一次覆盖）
2. 按用户意图处理：
   - 查看/列出 → 直接格式化返回
   - 分析/报告/对比 → 本地计算后返回

## 错误处理

- 校验错误 → 从错误信息提取可用值重试
- 权限/空数据 → 告知用户
